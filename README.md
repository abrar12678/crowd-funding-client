### ✨ Key Features
- **Dynamic Role-Based Dashboards:** Separate, tailored interfaces for Supporters, Creators, and Admins.
- **Smart Business Logic:** Platform earns via a credit exchange rate (Supporters buy at 10 credits/$1, Creators withdraw at 20 credits/$1).
- **Automated Refund System:** If a Creator rejects a contribution or deletes a campaign, credits are instantly refunded to the Supporters.
- **Real-time Notifications:** Floating pop-up notification system for contribution approvals, rejections, and campaign updates.
- **Campaign Management:** Creators can launch campaigns, track funds, and request withdrawals.
- **Admin Control:** Admins can approve/reject campaigns, manage user roles, and process withdrawal requests.
- **Credit Purchase System:** Integrated UI for purchasing platform credits (Stripe-ready implementation).
- **Advanced Security:** JWT-based authentication with persistent login and protected backend routes using custom middleware.
- **Reporting System:** Empowers users to report suspicious campaigns to the Admin for review.
- **Fully Responsive Design:** Seamless experience across mobile, tablet, and desktop devices with a modern Tailwind CSS UI.

### ⚙️ Tech Stack
- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS
- **Backend:** Node.js, Express, TypeScript
- **Database:** MongoDB (Native Driver)
- **Authentication:** JWT, Bcrypt
